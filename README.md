# Фабрика стальных каркасов (ЛСТК)

Многостраничный сайт-визитка компании, выполняющей проектные и строительно-монтажные работы по технологии ЛСТК (лёгкие стальные тонкостенные конструкции).

Сайт опубликован на GitHub Pages: **https://rudanastasia.github.io/lstk/**

## Стек

- HTML + SCSS + [TypeScript](https://www.typescriptlang.org/) (ES-модули), без фреймворков
- [Vite](https://vitejs.dev/) — сборка, dev-сервер с горячей перезагрузкой
- [Sass](https://sass-lang.com/) — препроцессор стилей
- [handlebars](https://handlebarsjs.com/) (vite-plugin-handlebars) — шаблоны и общие блоки страниц (шапка, подвал, хлебные крошки)
- [ESLint](https://eslint.org/) (+ typescript-eslint) и [Prettier](https://prettier.io/) — линт и форматирование кода
- Yandex Maps JS API 3.0 — карта на главной и странице контактов (типы: `@yandex/ymaps3-types`)
- Деплой — GitHub Actions на GitHub Pages (автоматически при пуше в `main`)

## Возможности

- адаптивная верстка для desktop, tablet и mobile;
- шаблонизация отдельных блоков html через handlebars-vite;
- многостраничная структура сайта с единой навигацией между страницами;
- мобильное hamburger-меню;
- слайдеры: проекты на главной, отзывы, блог и статьи (с поддержкой свайпа на мобильных);
- бесконечная карусель фото на детальной странице проекта: на десктопе активная карточка выделяется, на мобильных — обычная карусель по одному слайду;
- раскрытие длинных отзывов («Читать отзыв целиком» / «Свернуть»);
- breadcrumbs-навигация на внутренних страницах;
- форма обратной связи на странице контактов;
- форма отправки отзывов на странице отзывов (в модальном окне) с валидацией полей;
- пагинация в разделе отзывов, блоге, проектов;
- SVG-спрайт с иконками.

## Структура проекта

```
├── index.html            # главная страница
├── pages/                # остальные страницы (about, services, projects, ...)
├── css/                  # SCSS-исходники (styles.scss — главный файл со всеми @import)
├── scripts/              # TypeScript-модули (script.ts — общая точка входа со всеми import)
│   ├── mobile-menu.ts    # мобильное меню
│   ├── modal.ts          # модальное окно с формой отзыва
│   ├── slider.ts         # слайдеры и карусель портфолио
│   ├── reviews.ts        # раскрытие текста отзывов
│   ├── pagination.ts     # пагинация (отзывы, проекты, блог)
│   ├── map.ts            # Яндекс-карта
│   └── form.ts           # валидация и отправка форм
├── public/               # статика, которая копируется в сборку как есть
│   ├── assets/           # картинки, спрайты
│   └── customization.json # настройки оформления Yandex-карты
├── src/
│   ├── data/pages.ts     # данные страниц (хлебные крошки)
│   └── partials/         # шаблоны handlebars
├── tsconfig.json         # настройки TypeScript (только проверка типов, сборку делает Vite)
├── vite.config.ts        # конфигурация сборки (список HTML-страниц, base-путь)
└── .github/workflows/    # автосборка и деплой на GitHub Pages
```

## Разработка

Установить зависимости (один раз после клонирования репозитория):

```bash
npm install
```

Запустить локальный сервер разработки с автообновлением страницы при сохранении:

```bash
npm run dev
```

Сайт откроется по адресу `http://localhost:5173/lstk/` (обязательно с `/lstk/` в конце пути).

## Сборка

Собрать финальную версию сайта в папку `dist/`. Сначала запускается проверка типов TypeScript, и при ошибках сборка останавливается:

```bash
npm run build
```

Отдельно проверить типы (Vite типы не проверяет, а только убирает их из кода):

```bash
npm run typecheck
```

Локально проверить уже собранную версию (то, что реально попадёт на сайт):

```bash
npm run preview
```

## Линт и форматирование

```bash
npm run lint          # проверить код на ошибки ESLint
npm run lint:fix       # автоматически исправить, что можно
npm run format         # отформатировать все файлы Prettier
npm run format:check   # проверить, всё ли отформатировано
```

## Деплой

Деплой полностью автоматический: при каждом пуше в ветку `main` GitHub Actions ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)) собирает проект (`npm run build`, включая проверку типов) и публикует содержимое `dist/` на GitHub Pages. Прогресс и логи сборки — во вкладке [Actions](https://github.com/rudanastasia/lstk/actions) репозитория.

Вручную ничего собирать и заливать не нужно — достаточно закоммитить изменения в исходниках и запушить в `main`.
